            开场设置
            

              
              
              
              
            

            
              AI 先开场：执行时由智能体主动问候，turns 是用户的回应。
            
          


          
          

            
            

              填写后，每条用例的第一条用户消息将被替换为这段开场内容；执行测试时也会以它作为首条发送。
            

          

        


        

          
加载维度中...

        


        

          预计生成 0 条用例。生成会调用 LLM，耗时与并发取决于配置的模型。
        

        


        
        

          

            💡 PD 风格生成：以「测试要点 + P 级别」驱动，
            LLM 输出文本格式用例，后端解析后入库。适合定向回归。
          


          

          

            
            
          


          

          

          

          

            生成的用例会按 P 级别区分（写入 sub_type 字段），统一归到 alignment 维度便于统计。
          

        


        
        

          

            💬 动态对话生成：LLM 根据被测智能体的提示词，自动构造一批
            虚拟用户（人设、目标、最大轮数、终止关键词），
            生成的用例 dialogue_mode = dynamic，运行时由 LLM 扮演用户与智能体多轮对话。
          


          

            
            
          


          

            

              测试维度（可多选）
              

                
                
              

            

            

            
              选定的维度会传给 LLM，让它在这些维度间均衡分布生成用例（每条用例标注一个维度）。不选则按默认（alignment）。
            
          


          


          

          

            生成的用例将自动开启「动态对话」模式，可在用例编辑弹窗里查看 / 调整 persona、goal、max_turns 等字段。
          

        


        

          
          
        

        
点击「开始生成（后台）」会立即关闭弹窗，右下角会显示生成进度，可继续操作其他页面。
